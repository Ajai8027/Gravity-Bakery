Gravity Bakery - Latest source

Includes all seven pages, authentic bakery photographs, responsive styles, photo previews, WhatsApp enquiry flow, continuous occasions marquee, and hero animations.

Open index.html, or run python -m http.server 8000 in this folder and visit http://localhost:8000.
Upload the folder contents to any static website host. No build or dependencies needed.

Edit page content in HTML files, styles in style.css, interactions in app.js. Product definitions in app.js and HTML should be updated together; products.json is reference data.
Photo sources are documented in photo-sources.json.
